# AI-Supported Process Automation

## About

This is my personal learning project in process analysis, BPMN, low-code automation, and applied AI.

I am studying Cognitive Science with a specialization in Artificial Intelligence at the University of Osnabrück. Through this project, I want to develop practical skills for identifying process improvement opportunities and designing useful automation solutions.

## The problem

In a typical IT support process, employees submit requests that need to be reviewed, categorized, and forwarded to the appropriate team.

This project explores how the process could be made more efficient and where automation or AI might help.

## Goals

- Map the existing process using BPMN.
- Identify repetitive tasks and possible improvements.
- Design an automated workflow for handling support requests.
- Explore Python and low-code automation tools.
- Develop test cases to evaluate the reliability of an AI-supported solution.
- Document risks, limitations, and the need for human review.

## Tools

Planned tools include BPMN modelling, Python, Microsoft Power Automate, and Microsoft Copilot Studio, depending on available access.
